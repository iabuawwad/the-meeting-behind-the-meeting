# Book Summary Reference Guides

These files are user-created summary and reference guides.

They are not full books. They are not replacements for the original works. They are not official publications from the original authors or publishers.

Users are encouraged to buy and read the original books for the complete context, arguments, examples, and authorial framing.

The files in this folder are used as analytical reference material for **The Meeting Behind the Meeting**. They support the skill's behavioral, communication, trust, influence, culture, voice, and nonverbal analysis layers.

## Use Rules

- Use these guides as supporting lenses, not as source text to reproduce.
- Do not quote long sections.
- Do not reproduce book content in outputs.
- Convert reference material into evidence-based meeting analysis.
- Always separate fact, signal, interpretation, alternative explanation, confidence, and recommended action.

## Responsible-Use Guardrails

The skill must not:

- Diagnose people.
- Claim certainty about motives.
- Treat lie detection as factual.
- Infer body language without transcript evidence, behavioral notes, visual markers, pause markers, interruption markers, or tone markers.

When evidence is weak, lower confidence or do not use the reference.
