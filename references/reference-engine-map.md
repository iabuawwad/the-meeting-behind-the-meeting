# Reference Engine Map

This file explains how the operating references map to the skill frameworks. Use it to decide which reference to load for a given analysis need.

## Main Use In The Skill

Use this reference when selecting supporting material for a meeting analysis. It keeps the core `SKILL.md` concise by routing deeper concepts to the right reference file.

## Signals To Look For

- The analysis requires a specific lens beyond factual reconstruction.
- The transcript includes tone, nonverbal, influence, trust, culture, or style signals.
- The agent needs guardrails before making an advanced claim.
- The output needs evidence-linked interpretation rather than summary alone.

## Guardrails

- Load only the reference needed for the analysis task.
- Do not use references to bypass the transcript quality gate.
- Do not turn source concepts into claims of private-thought access, truthfulness certainty, clinical assessment, or private intent.
- Keep all conclusions tied to transcript evidence.
- Treat references as operating lenses, not authorities for overclaiming.

## Confidence Rules

- Use high confidence only when the transcript has direct evidence and the relevant framework criteria are met.
- Use medium confidence when evidence is present but incomplete or open to alternatives.
- Use low confidence when the signal is weak, transcript quality is limited, or the reference is only loosely applicable.
- If the relevant reference requires behavioral, tone, or visual markers and the transcript lacks them, do not use that reference for interpretation.

## When Not To Use This Reference

- When the task only needs a factual summary.
- When the user asks for diagnosis, lie detection, or certainty about private thoughts.
- When the transcript is too poor to support advanced analysis.
- When a single specialized reference is already clearly selected.
